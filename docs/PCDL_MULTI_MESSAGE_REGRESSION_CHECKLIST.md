# PCDL Multi-Message Regression Checklist

1. Admin selects Day 1 and sees Message 1.
2. Admin adds Message 2 to Day 1.
3. Refresh page; Message 2 persists.
4. Today page shows both messages in order.
5. User completes Message 1 only.
6. User completes Message 2 only.
7. Progress records store separate `message_item_id` values.
8. Member cannot edit schedule.
9. Admin can edit schedule.
10. `other_label` displays as a day tag/note, not as a separate message.
