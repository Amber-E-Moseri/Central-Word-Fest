# PCDL Permissions

## Member
- Can access content
- Can complete messages
- Can post reflections
- Can view community
- Can choose accountability partners
- No stats dashboard

## Bible Study Class Teacher
- Same as Member

## Cell Leader
- Same as Member

## Coordinator
- Same as Member
- Can see fellowship stats
- Can see people in assigned fellowship
- Can click person detail

## Pastor
- Same as Coordinator
- Assigned to one fellowship

## Subgroup Pastor
- Can see assigned subgroup fellowships only

## Group Pastor
- Can see all fellowships
- Assigned only by admin

## Admin
- Full system access
- Assigned only by admin
